
# Daily Habit and Exam Prep Streak Tracker

## About the Project
A student productivity application designed to track daily habits, study schedules, exam preparation and study streaks.

## Objectives
- Build consistent daily habits.
- Track exam preparation.
- Monitor daily study hours.
- Maintain study streaks.
- Improve student productivity.

## Technologies Used
- Python
- Streamlit
- SQLite
- Pandas
- Matplotlib

## Features
- Daily Habit Tracker
- Exam Preparation Tracker
- Study Hours Monitoring
- Streak Counter
- Progress Dashboard
